# AI-Engineering-Lab

一个人的：研究院 + 实验室 + 内容工作室 + FDE + 产品公司。
你本人负责 Vision / Research / Judgment / Customer，AI Agent 负责 Research / Coding / Evaluation / Content / Operation。

## 本地预览

这是一个无需构建工具的静态页面，直接用浏览器打开 `index.html`，或运行：

```bash
python3 -m http.server 8000
```

页面围绕「AI Agent × 软件研发 × 算力」展开，包含每周的深度观点、实验、科普和行业观察，以及四阶段成长路线。
